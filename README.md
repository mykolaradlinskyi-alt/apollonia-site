# АПОЛЛОНІЯ — сайт клиники

Статичный лендинг стоматологической клиники-студии Сергея Радлинского (Полтава).

## Где живёт сайт

GitHub Pages: ветка `main`, корень репозитория.

## Как редактировать

Весь сайт — один файл `index.html` (HTML + inline CSS + base64 фавиконки).

```bash
cd ~/projects/apollonia-site
# правишь index.html
git add index.html
git commit -m "правка: <что изменил>"
git push
```

Через ~30–60 секунд правки появятся на боевом URL.

## Структура

- `index.html` — главная страница сайта
- `CNAME` — кастомный домен (если подключён)
